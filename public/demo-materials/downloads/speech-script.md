## 什么是 Skill（Slide 3 · 2:00 - 4:00）

先说定义：

**Skill = 结构化的 prompt 知识库**

它通常是一个文件，比如：

```
SKILL.md
```

里面不是一句 prompt，而是一整套约束，包括：

- 设计规范（Design Tokens）
- 组件使用方式
- 布局模式
- 反模式约束

你可以把它理解成：

👉 **不是在和 AI 说“帮我写个页面”**
👉 而是给它一份“施工图纸 + 规范文档”

一个很关键的点是：

> AI 默认是没有“团队规范”的
> Skill 的本质是把“团队经验”注入进去

## AI 生成前端的典型问题（Slide 4 · 4:00 - 6:00）

我们先直面问题。

如果你直接让 AI 生成页面，大概率会出现这几类问题：

### 1. 布局混乱

- padding、margin 完全随机
- 对齐不统一
- 栅格系统不存在

👉 本质原因：AI 不理解“视觉节奏”

------

### 2. 颜色失控

- 每次生成颜色都不一样
- 没有主色、副色概念

👉 本质原因：没有 design token

------

### 3. 组件重复造轮子

- 每页一个 button 写法
- 卡片结构不统一

👉 本质原因：没有组件抽象

------

### 4. 代码不可维护

- class 命名混乱
- 风格不一致

👉 本质原因：没有规范输入

------

总结一句话：

> AI 的问题不是“不会写代码”，而是“没有约束”

------

## Skill 的三大模块（Slide 5 · 6:00 - 8:00）

我们把 Skill 拆成三个核心模块：

------

### 1. 设计规范模块

定义：

- 颜色
- 字号
- 间距系统

例如：

```
Primary: #1C4E80
Spacing: 0.5rem scale
Font: Calibri
```

------

### 2. 组件库模块

不是代码库，而是：

👉 **“如何使用组件”的描述 + 示例**

比如：

```
Card:
- rounded-lg
- shadow-md
- padding 1rem
```

------

### 3. QA 检查模块

这个很多人会忽略，但其实非常关键：

- 是否溢出？
- 是否对齐？
- 是否颜色一致？

👉 相当于给 AI 加一个“自检步骤”

------

## 策略一：Design Token 注入（Slide 6 · 8:00 - 11:00）

这是最核心的一步。

如果你不做这个：

👉 AI 一定会“随机选色”

------

### 做法

在 Skill 里明确写：

```
Use ONLY these colors:
- Primary: #1C4E80
- Secondary: #CADCFC
- Accent: #0D9488
- Background: #FFFFFF
```

再加上：

```
Spacing system:
- 0.5rem
- 1rem
- 1.5rem
- 2rem
```

------

### 关键点

你不是在“建议”AI
你是在“限制”它

------

### 演示（这里停 1 分钟）

现场可以演示两次生成：

**Prompt 1：没有 Skill**
→ 页面颜色混乱

**Prompt 2：带 Skill**
→ 明显统一

------

## 策略二：布局模式库（Slide 7 · 11:00 - 14:00）

第二个关键点：

👉 **不要让 AI 自己“发明布局”**

而是给它“布局模板”

------

例如定义：

```
Layout Patterns:

1. Two-column (text + image)
2. Icon row (circle icon + title + desc)
3. Grid 2x3 cards
4. Hero with overlay
```

------

### 为什么有效？

因为：

> 布局不是随机组合，而是“有限集合”

------

### 演示点

让 AI：

- 生成“产品介绍页”

对比：

- 无布局约束 → 很散
- 有 layout pattern → 很稳定

------

## 策略三：反模式清单（Slide 8 · 14:00 - 16:30）

这是最容易被低估，但效果极强的一步。

------

### 反模式示例

你直接写在 Skill 里：

```
DO NOT:
- Use accent lines for headings
- Let text overflow containers
- Use cream backgrounds by default
- Repeat same layout for all slides
```

------

### 为什么这一步重要？

因为：

👉 AI 更容易“避免错误”，而不是“创造完美”

------

### 本质

这是在做：

**负约束（Negative Constraints）**
